1 Activation de votre Licence

DoulGet nécessite une licence valide pour fonctionner sur votre ordinateur. Suivez ces étapes simples pour activer votre copie.

Récupérer votre identifiant (HWID)

  • Ouvrez l'application DoulGet.
  • Copiez le code HWID affiché dans le rectangle bleu.
  • Envoyez-le à votre revendeur pour obtenir votre clé de licence.

2 Installation de l'Extension Chrome

L'extension est le cerveau de DoulGet. Elle permet de détecter automatiquement les boutons de téléchargement sur vos sites préférés.

Étape A : Activer le mode développeur

Ouvrez la page chrome://extensions dans votre navigateur Google Chrome ou Edge.

Activez l'interrupteur "Mode développeur" en haut à droite.

Étape B : Charger le dossier

  • Cliquez sur le bouton "Charger l'extension non empaquetée".
  • Sélectionnez le dossier extension_clean de DoulGet.

Étape C : Vérification

L'extension DoulGet Assistant doit maintenant apparaître parmi vos extensions actives.

3 Utilisation sur YouTube

Une fois l'extension installée, le téléchargement devient un jeu d'enfant sur YouTube et d'autres plateformes.

Apparition du menu

Sur une page vidéo, l'extension affiche un menu contextuel élégant sur le bord de l'écran ou au-dessus de la vidéo.

Choix du Format

DoulGet vous propose le choix : Télécharger en mode Vidéo (haute qualité) ou Audio (extraction MP3).

Lancement du téléchargement

Le bouton se transforme pour vous montrer la progression en direct. Vos fichiers sont gérés par le mode Turbo de l'application logicielle.

Confirmation Finale

Une notification s'affiche dès que le téléchargement atteint 100%. Votre vidéo est prête !

4 Paramètres et Corbeille

Personnalisez votre expérience et gérez vos anciens fichiers.

Réglages Avancés

  • Changez le dossier de destination.
  • Réglez le nombre de téléchargements simultanés pour économiser votre bande passante.

La Corbeille

Les téléchargements annulés sont stockés ici. Vous pouvez les reprendre à tout moment sans recommencer à zéro.

Important : Gardez toujours l'application DoulGet ouverte pendant que vous utilisez l'extension pour garantir une vitesse maximale.
